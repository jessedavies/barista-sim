# Barista game (working title: Shaky Hands)

A first-person barista game in the browser: physics hands, a Melbourne specialty café, Australian coffee orders.

- `toys/hand.html`: the playable toy. It covers the full flat white loop: grind, tamp, shot, knock box, milk, steam, pour, pass.
- `tools/`: a no-cache dev server, plus model inspect and measure pages.
- `PLAN.md`: the plan and its revisions. `CREDITS.md`: model and asset licences (CC-BY, CC0, MIT).

Run it with `python3 tools/serve.py 5230`, then open http://localhost:5230/toys/hand.html
